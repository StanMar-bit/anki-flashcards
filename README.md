## How to use

1. Download the open source flashcard tool [Anki](https://apps.ankiweb.net).
2. Download the relevant `.apkg` file from the Available Decks section above.
3. Import the deck by double clicking it (when Anki is installed and running), or in the menu go to **File → Import**.

## Contributing

Feel free to make PRs for new flashcards / improvements!

I also recommend the following extensions if creating your own flashcard decks:

- [Image Occlusion Enhanced](https://ankiweb.net/shared/info/1374772155) to create flashcards for images, especially helpful for cognitive science images and tables related to brain regions.
- [Enhanced Cloze](https://ankiweb.net/shared/info/1990296174) for lists of things to remember.

If something is wrong or you have a suggestion, feel free to create an issue.
